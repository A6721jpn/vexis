# リリースノート: VEXIS-CAE

本ドキュメントでは、自動解析ワークフローシステム「VEXIS-CAE」の各バージョンの変遷と主要な変更点を、開発の軌跡とともに詳細に記録しています。

## Version 1.6.0 (Rust/Vulkan 統合ブランチ) - In preparation
**統合対象期間**: 2026-02-20 〜 2026-03-23  
**このブランチでの位置づけ**:
- `src/version.py` は `1.6.0` に更新し、Rust/Vulkan 系実装を main 系列へ統合するためのブランチとして扱います。
- Rust/Vulkan 実装の最新ソース基準は 2026-03-23 時点の `worktrees/vexis-rust-vulkan` 系コミット群です。
- 一方で、安定版リリースとしての最新は引き続き `v1.4.4` であり、`1.6.0` は検証と整理が完了するまで準備中の扱いです。

**統合準備メモ**:
- Rust コアの build artifact はローカル生成物として扱い、`src/libs/vexis_vulkan_core/target/` を ignore 対象にします。
- `build_rust.py` はプロジェクト仮想環境の Python を優先して使い、`maturin` 実行・import 検証・PyInstaller 実行を同一 interpreter に揃えます。
- GUI の AppUserModelID も `src/version.py` の版番号を参照するように変更し、Windows 側表示の版不整合を避けます。

## Version 1.4.4 (結果表示の高速化と表示品質改善) - Latest stable release

**開発日**: 2026-02-11
結果表示の3Dビューを中心に、操作追従性・ロード速度・表示の正確性をまとめて改善しました。

**前Version (1.4.3) との差分**
- 結果3D表示の更新経路を軽量化し、スライダー操作中の追従性を大幅改善。
- 事前全展開からオンデマンド方式へ変更し、CPU高負荷時の初期ロード待ちを短縮。
- ワイヤーフレームをヘキサ境界エッジのみに限定し、誤解を招く内部/三角分割線を排除。
- 凡例レンジを「全解析ステップ横断 min/max」に統一し、時刻ごとの色ぶれを解消。
- stress/strain を節点平均ベースで描画し、要素ブロック状の見え方を滑らか化。

- **パフォーマンス改善:**
    - **スライダー追従性の向上**: 更新キューと軽量描画モードを導入し、ドラッグ中のカクつきを大幅に低減。
    - **ロード初期応答の改善**: 全ステップの事前展開をやめ、必要時キャッシュ＋バックグラウンド計算へ変更。CPU占有時の初期待ちを短縮。

- **表示品質改善:**
    - **ヘキサメッシュ専用ワイヤーフレーム**: 境界ヘキサ面の真のエッジのみを抽出して描画し、三角分割由来の誤解を招く線表示を解消。
    - **ワイヤーフレームの変形追従修正**: スライダー操作時にワイヤーフレームが変形後形状へ正しく追従するよう修正。
    - **節点球体ノイズの除去**: ワイヤーフレーム交点に見えていた黒い球体/丸表示を抑制。
    - **ズーム/視点保持**: スライダー更新後もカメラ位置を維持し、拡大状態がリセットされないように修正。
    - **全ステップ共通レンジ対応**: コンター凡例の最小/最大を「全解析ステップ横断」の値に統一し、時刻ごとの色基準の揺れを解消。
    - **stress/strainの滑らか表示**: セル値を節点平均して表示し、要素ブロック状の色分けを改善。

## Version 1.4.1 (メッシュ表示の修正)
**開発日**: 2026-01-09
3Dビューワーにおけるメッシュ表示の不具合を修正したパッチリリースです。

- **バグ修正:**
    - **Hex20要素の対角線表示問題を解消**: メッシュプレビューおよび結果表示において、六面体要素（Hex20）が内部で三角形分割されることで発生していた対角線表示を修正。`extract_all_edges()` により真のセルエッジのみを描画するよう変更。
    - **ウィジェット重複登録の修正**: `mesh_preview.py` で `addWidget` が2回呼ばれていた問題を修正。
    - **バッチ再開時のステータスリセット**: Stop後にStartを押すと停止したジョブがスキップされる問題を修正。Start時に全ジョブをPENDINGにリセットし、常に先頭から実行されるよう変更。

- **新機能:**
    - **ソルバーステータス表示**: ステータスバー右端にソルバーの検出状態を表示。Embedded（同梱版）/ External（外部版）/ Solver Not Found（黄色警告）の3状態を表示し、解析開始時に自動チェック。

    - **グラフの動的リサイズ対応**: Force-Stroke グラフを PNG 画像表示から Matplotlib の `FigureCanvasQTAgg` 埋め込みに変更。ウィンドウサイズに自動追従。
